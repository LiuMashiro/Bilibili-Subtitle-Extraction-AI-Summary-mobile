# B站字幕获取、AI分析工具 移动端

**Bilibili-Subtitle-Extraction-AI-Summary-**

实现字幕提取、AI内容总结（并可追问）并依据评论区热门评论进行舆情分析。

[**建议使用更好用更方便的PC油猴脚本版**](https://github.com/LiuMashiro/Bilibili-Subtitle-Extraction-AI-Summary-Ad-Skipping)

![image.png](https://scriptcat.org/api/v2/resource/image/ODyLJCgNTeIs9JZC)



## 主要功能

- 自动获取视频CC字幕、AI字幕，支持多格式下载
- AI总结视频内容与评论区舆情分析
- **当前处于早期测试版，预期会有一些问题**

## 慢速使用

由于本小程序未上架，您必须在电脑上下载运行一次以推送到手机上。无需上架，也无需始终连接电脑。

- 在Release中下载Source code(zip)并解压
- [在微信开放平台中注册一个小程序](https://mp.weixin.qq.com)，选择个人主体，无需认证，信息随意填写即可（因为无需上架，此步骤仅需获取一个AppID）
- 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，导入本程序，勾选微信云开发（保持在测试期可以免费使用）
- 选择顶部预览-自动预览，将程序推送到手机
- 在手机上按照指引使用

## 使用须知

为什么要使用云环境？——如果不使用云环境，微信小程序强制携带小程序标识，会被B站拦截。
